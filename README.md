# مكتبة إدارة الأعمال الطلابية — GitHub Pages

موقع عربي متجاوب لطلاب قسم إدارة الأعمال بالمعهد التكنولوجي العالي بالعاشر من رمضان — فرع مطروح. يستخدم HTML وCSS وJavaScript، وخط Cairo.

## الفكرة
- ضع أي ملفات أو مجلدات تريد عرضها داخل مجلد `debo/` في جذر المستودع.
- لا تكتب أسماء الملفات داخل JavaScript؛ GitHub Actions ينشئ `debo-index.json` تلقائيًا في كل نشر.
- الموقع يعرض المجلدات أولًا ثم الملفات، ويدعم الدخول للمجلدات الفرعية والرجوع عبر مسار التنقل والبحث في المكتبة والفلترة حسب نوع الملف.
- الملفات تفتح من رابطها المنشور على GitHub Pages، ويمكن تحميلها من الموقع.

## خطوات الرفع
1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المشروع كما هي، مع مجلد `debo`.
2. ضع الكتب والمحاضرات والمجلدات داخل `debo/`. أسماء الملفات العربية والمسافات مدعومة.
3. تأكد أن الفرع الأساسي اسمه `main` أو `master`.
4. افتح **Settings → Pages** في المستودع، ثم اجعل **Build and deployment → Source** = **GitHub Actions**.
5. افتح تبويب **Actions** وانتظر اكتمال `Build and deploy student library`. بعد كل push إلى الفرع الأساسي سيُعاد إنشاء الفهرس ونشر الموقع.
6. رابط الموقع سيظهر في **Settings → Pages** بعد نجاح أول عملية نشر.

## إضافة أو حذف محتوى
أضف أو احذف ملفات ومجلدات داخل `debo/` ثم اعمل Commit/Push. لا تعدل `debo-index.json` يدويًا؛ يتم توليده في النشر. المجلدات الفارغة لا تظهر في GitHub إلا إذا احتوت على ملف، لذا ضع ملف `.gitkeep` بداخل المجلد الفارغ إذا أردت الاحتفاظ به.

## ملاحظات مهمة
- GitHub Pages استضافة ثابتة؛ لا يستطيع JavaScript استكشاف المجلدات على الخادم مباشرة. لذلك يتولد فهرس JSON آليًا عبر GitHub Actions.
- كل ملف داخل المستودع المنشور سيكون متاحًا للعامة. لا ترفع بيانات شخصية أو ملفات لا تملك حق مشاركتها.
- حد GitHub Pages المعتاد للموقع المنشور 1 GB، مع حدود نشر/استخدام أخرى؛ تجنب رفع ملفات ضخمة جدًا، واستخدم Drive أو استضافة ملفات مناسبة إذا احتجت سعات كبيرة.
- GitHub Pages يعرض PDF والصور والنصوص المتوافقة داخل المتصفح عادةً؛ بعض أنواع الملفات تحتاج برنامجًا خارجيًا.
- لو المستودع اسمه مثلًا `student-library`، لا تضف اسم المستودع يدويًا للمسارات؛ الموقع يستخدم روابط نسبية لتعمل على GitHub Pages.

## الملفات
- `index.html` — واجهة الموقع.
- `style.css` — التصميم المتجاوب.
- `app.js` — البحث والتصفح والعرض.
- `debo/` — كل محتوى المكتبة الذي تريد نشره.
- `scripts/build_index.py` — يولد فهرس المحتوى.
- `.github/workflows/deploy.yml` — ينشئ الفهرس وينشر الموقع تلقائيًا.
